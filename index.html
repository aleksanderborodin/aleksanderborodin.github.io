Yoola Explain

A browser extension that simplifies Terms of Service by providing AI-generated summaries. Extracts ToS text, sends it to an LLM via OpenRouter, and returns structured summaries with key points, data collection info, and warnings. Multi-language support with caching.

LLM safety · Python · LLM APIs · Prompt Engineering

Prefix Injection Jailbreak

Prefix attacks on LLMs inspired by BBC's Choice Blindness experiments. Simulating the start of a model's response to a forbidden query tricked Gemini 2.5 Pro and DeepSeek R1 into completing harmful answers — near-100% success on MaliciousInstruct vs. near-zero baseline.
